# Complete eight-role model profiles

Every admitted model is now evaluated for all eight roles. The former per-role admission rule could rank a model as Implementer while omitting it as Strategist or Security Reviewer. Incomplete evidence no longer creates a different model universe for each role.

Measured benchmark fields and measured role contributions remain intact. A missing contribution uses an explicit analogy to up to three fully measured eight-role AA profiles, selected by mean absolute distance on at least two shared normalized core benchmarks. Only observed profiles anchor this completion; estimates never become training data. External targets must first pass their documented evidence recipe, whose observed reference models provide matching features.

Ranking uses the minimum observed anchor contribution minus a policy margin: 25 points, at least 35 for security, and at least 40 for external cross-domain completion. The range is a heuristic envelope, not a calibrated confidence interval. A security analogy is a role score and never a measured Cyber Index. These margins do not prove cross-domain predictive accuracy.

If evidence is insufficient to complete the profile, the whole model is excluded from rankings, percentiles and portfolios. One issue is emitted for its identity, even if several roles or commercial variants are affected. Jev remains a normal non-comparable exclusion. Detailed missing observations stay in the JSON as diagnostics, rather than repeated refresh errors.

The statistical Intelligence and CAI estimators stay disabled. Completion never estimates Intelligence. Existing reviewed external Intelligence analogies and the one-estimated-seat portfolio cap remain. Coding evidence independence uses the actual selected role; an unrelated security estimate cannot couple two observed coding measurements.

Validation on the current public input: 66 of 68 active offers have all eight role scores, with the two Jev offers excluded. Twenty offer profiles are entirely observed; 46 have at least one explicitly estimated role. The three portfolio selections are unchanged from the preceding live snapshot under the same inputs.

Behavior checks cover full-profile admission, whole-model exclusion with one issue, preservation of observations and Intelligence, measured-only anchors, independent coding evidence, portfolio constraints, and preservation of all published artifacts on source/security failure.
