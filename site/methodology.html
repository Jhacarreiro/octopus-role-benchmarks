Role quality and portfolio modes

The detailed ranking table exposes role-quality signals and cost-per-quality values. The eight recommendation cards are generated separately as constrained portfolios: Quality, Balanced and Budget.

QualityIntelligence floor 0.90 → adaptive ≥5-family pool → maximize total Role Quality
Balancedlatest-gen cost cutoff (mean + 2σ) → recompute best Intelligence → floor 0.85 → maximize Σ(Role Quality − 3.5 × effective task cost)
Budgetlatest-gen cost cutoff (mean + 2σ) → recompute best Intelligence → floor 0.80 → minimize total effective task cost

For Balanced and Budget, cost outliers are identified first from the full latest-generation scored universe. After those models are removed, the best eligible Intelligence Index is recomputed; the requested 0.85/0.80 floor is then applied to that filtered baseline. If the resulting pool cannot support a feasible portfolio, the floor is lowered in 0.005 steps. Quality uses the unfiltered Intelligence baseline. Every final lineup still requires at least four families and allows at most two seats per family.

There are no mandatory models, manual Fable blacklist, or per-role quality floor. Code Reviewer must differ from both implementation identities. Implementer Heavy must differ from Implementer and must have at least +2.0 AA Intelligence Index points.

Security Reviewer

Security Reviewer = Vals AI CyberBench Overall, directly. The previous SciCode/GPQA/HLE/Omniscience/LCR proxy has been removed. If a model has no direct CyberBench score, it is simply ineligible for this one role.

Balanced and Budget share the same mean + 2σ plan-adjusted cost-outlier cutoff. The cutoff is computed from the full latest-generation scored universe, then the Intelligence baseline is recomputed after exclusions. Balanced additionally applies a linear penalty of 3.5 Role Quality points per $1 of effective task cost; Budget minimizes total plan-adjusted task cost.

CommandCode credit burn and plan-adjusted Cost per Task

Price per million tokens is not used as the primary denominator. Artificial Analysis measures the token mix consumed per Intelligence Index task. Those measured non-cached input, cache-read, cache-write and output tokens are repriced with the current effective CommandCode Max rates.

task cost = input tokens × CC input + cache-read × CC cache-read + cache-write × CC cache-write + output × CC output

If CommandCode exposes no separate cache rate, normal input price is used. Active CommandCode promotions are retained.

CAI*: current observation, calibrated history, then estimator

If the current Coding Agent Index version has not re-evaluated a family, a prior observed CAI may be mapped onto the current scale with a validated overlap-derived degradation factor. Only families with neither current nor calibratable historical CAI use the estimator:

CAI* = 50% Ridge prediction + 50% inverse-distance 5NN prediction

Ridge (λ=1) uses SciCode, GPQA, HLE, LCR, GDPval, AA-Omniscience Index (normalized to 0–100) and log(Output Tokens/Task). 5NN uses SciCode, GPQA, HLE and LCR, standardized across the observed CAI training set, with Euclidean distance and inverse-distance weighting over the five nearest models.

The estimator is trained only on unique model families with current-version observed AA Coding Agent results. Calibrated historical values never train the estimator, and commercial CommandCode variants never count as extra training examples.

SciCode fallback: current observation first; otherwise a last observed value no older than 14 days may be used only after overlap calibration against current observations passes MAE/max-error guardrails. The calibration factor is capped at 1. Ridge is a third-line fallback and is usable only when its original leave-one-out guardrails pass; otherwise the family is source-incomplete.

Coverage and failure rules

Universal weighted-role components, CommandCode Cost per Task and final CAI* must cover the scored model-family universe according to the published coverage rules. Security Reviewer is role-specific and uses direct CyberBench coverage instead. Stealth/unresolved rows remain visible as UNSCORED. Validation continues to fail closed when estimator/ranking guardrails are breached.

Raw model mappings, current/historical-calibrated/estimated CAI*, SciCode fallback provenance and calibration diagnostics, Ridge/5NN components, role scores, task costs and final Ranking Values are all preserved in the public JSON snapshot.

Portfolio regeneration

After refreshes, Octopus regenerates the complete Quality, Balanced and Budget portfolios under the current deterministic policy. Review data records portfolio-level changes rather than evaluating independent hand-picked seat swaps.

The policy file contains rules, not selected model names. Generated selections and their requested/effective Intelligence floors, pre/post-filter Intelligence baselines, family counts, costs and Balanced/Budget outlier statistics are published in site/data/lineups.json.
